# Referenciák

Ide tegyél 3–5 minta reelt (képernyőfelvétel vagy képernyőkép), amelyeknek a stílusát szeretnéd. Az ágens képkockákat vesz ki belőlük, és a tipográfiát, a ritmust és az átmeneteket ezekhez igazítja. Tartalmat, logót vagy márkaelemet nem vesz át belőlük.

A mappa tartalma nem kerül fel a GitHubra (csak ez a leírás).
