# Márkaelemek

Ide kerül az Aetherpontis logó (PNG átlátszó háttérrel vagy SVG), pl. `aetherpontis-logo.png`. Render előtt a rendszer automatikusan a `public/m/` mappába másolja.

Használat: az `ayarlar/stilusok.json` `aetherpontis` stílusában a `"logo"` mezőbe írd a fájlnevet (pl. `"logo": "aetherpontis-logo.png"`). Ekkor a CTA jelenet a logót is mutatja. A színkódokat ugyanott írd át, és töröld az `"ideiglenes": true` sort.
